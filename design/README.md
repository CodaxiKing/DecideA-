# Design do DecideAí

Código-fonte do canvas de telas: [DecideAí — Telas](https://claude.ai/artifact/6wmYMEaGpwAxT4oAxMszw1).

- `canvas/canvas.json`: mapa das pranchas.
- `canvas/*.dc.html`: uma prancha por tela.
- `canvas/app.css`: tokens e componentes visuais.
- `canvas/img/`: logo e fotos.

As fotos vêm do Pexels e servem ao protótipo. Os créditos estão no `canvas.json`, na nota "Fotos: Pexels".
